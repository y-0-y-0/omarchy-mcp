# [omarchy-mcp] Context — Omarchy and Hyprland Lua modernization (2026-10-30)

Status: open. Continue PR #1 locally; do not push, merge, deploy, run the installer, or modify system configuration without explicit authorization. Preserve user configuration and existing work. No Context.md existed at the start.

Goal: audit all 27 MCP tools, address security and compatibility issues, verify with unit/integration/security tests and isolated installation, document evidence and limitations, and obtain independent review. Do not present mocks as real compositor validation.

Baseline: PR branch draft/omarchy-modernization, commit 5ca9ad6, originally checked out main clean. Python 3.11.6; declared Python >=3.10, MCP <2, Pillow and pytesseract. This orb has no Hyprland, grim, Wayland session, or installed Python project dependencies.

Findings: Hyprland 0.56.2 supports Lua and legacy configuration managers; 0.57.0 is Lua only. In Lua mode hyprctl dispatch evaluates Lua, so legacy untrusted arguments can cause execution before an error. Omarchy 4.0.6 loads bootstrap, defaults, user modules and generated toggles; never overwrite or regenerate user configuration. The allowlist lacks ownership/permissions checks and executable identity guarantees; it is not a sandbox. MCP validation errors may expose inputs. Screenshot coordinates can be wrong for negative monitor origins and scaling; automatic clicks can target unintended locations. Hyprland 0.57 workspace ids may be absent; client monitor IDs differ from names. Other input validation and composite action issues need regression coverage.

Official references: https://wiki.hypr.land/0.57.0/configuring/core/advanced-configuration/using-hyprctl/ ; https://wiki.hypr.land/0.57.0/configuring/core/dispatchers ; https://github.com/omacom/omarchy/blob/v4.0.6/config/hypr/hyprland.lua ; https://github.com/hyprwm/Hyprland/blob/v0.57.0/src/ipc/s1/Commands.cpp ; https://man.archlinux.org/man/grim.1.en .
